## 项目简介

**耘智** 是一款基于 OpenHarmony 的智慧农业远程控制系统，由智能主板（STM32 + ESP32）、鸿蒙网关（BearPi-HM\_Nano）、OpenHarmony APP 及华为云 IoTDA 四大模块构成。用户通过手机 APP 即可远程监测农田环境、管控农业设备，实现灌溉、补光、通风、害虫防治等全流程智能化管理。系统搭载 豆包大模型，提供 AI 农业专家问答、拍照识病、植物百科等智能服务，搭配太阳能供电模块，践行绿色农业发展模式。

## 架构设计

项目采用 **MVVM + Service** 四层架构：

```
┌─────────────────────────────────────┐
│              View 层                 │  ← ArkUI 页面（pages/ + components/）
├─────────────────────────────────────┤
│           ViewModel 层              │  ← 业务逻辑、状态管理（viewmodel/）
├─────────────────────────────────────┤
│            Service 层               │  ← 网络请求、AI、IoT、认证封装（services/）
├─────────────────────────────────────┤
│            Model 层                 │  ← 数据结构定义（model/）+ 本地数据库（data/）
└─────────────────────────────────────┘
```

- **View 层**：负责 UI 渲染与用户交互，通过 @State / @StorageLink 绑定数据
- **ViewModel 层**：处理业务逻辑，连接 View 与 Service
- **Service 层**：封装华为云 IoT、火山引擎 AI、华为 AGC 认证等外部交互
- **Model 层**：定义数据结构，管理 SQLite 本地数据库（7 张表）

### 数据流

```
传感器 → STM32 → UART → BearPi-HM_Nano 网关 → MQTT → 华为云 IoTDA → HTTP → APP
                                ↑                                      ↓
                          设备控制命令 ←────────────────────────────── APP
```

- 传感器数据每 30 秒上报一次到华为云 IoTDA
- APP 通过 HTTP 调用华为云 API 获取设备影子和下发控制指令
- 设备指令经 MQTT QoS1 通道下发，响应时延 ≤ 300ms
- 预警服务 5 分钟轮询一次，对比环境参数与阈值

## 功能模块

### 1. 首页（Home）

- **天气展示**：获取当前位置的天气状况、温度、湿度、降水、风速风向、光照等
- **快捷入口**：提供 AI 对话、植物百科、拍照识病等功能的快捷入口
- **农业资讯**：展示最新农业新闻列表，点击可跳转 WebView 查看详情
- **预警提醒**：首页图标红点提示未读预警消息

### 2. 地块管理（Monitor）

- **地块列表**：支持宫格/列表两种展示模式，展示地块封面、名称、种植作物
- **添加地块**：输入地块名称、绑定网关设备 ID（支持从云平台设备列表点选填充）、选择种植作物与生长阶段
- **编辑/删除地块**：长按或点击编辑图标进入编辑弹窗，支持修改信息和删除
- **首页展示选择**：可设置特定地块在首页优先展示

### 3. 地块详情与设备控制（MonitorDetail）

#### 视频监控

- 绑定 ESP32-CAM 视频流 IP 后，可实时查看摄像头画面
- 支持全屏放大播放、暂停/关闭视频

#### 环境数据展示

- 实时显示空气温度、空气湿度、土壤湿度、土壤温度、光照强度、CO₂ 浓度
- 设备电量实时显示
- 环境参数历史趋势折线图（可选择最近 24 小时 / 7 天，按参数切换查看）

#### 手动控制模式

- **水泵（灌溉）**：开关控制 + 定时启停设置
- **RGB-LED 补光灯**：开关控制 + 四色切换（红/暖白/蓝/混色）+ 定时设置
- **排气扇**：开关控制 + 定时启停设置
- **农药弥雾机**：开关控制 + 定时启停设置

#### 自动控制模式

- 切换到自动模式后，设备根据阈值自动启停：
  - 土壤湿度 < 阈值 → 水泵自动开启
  - 温度 > 阈值 → 风扇自动开启
  - 光照强度 < 阈值 → LED 补光灯自动开启
  - CO₂ 浓度 > 阈值 → 排气扇自动开启
  - 摄像头识别到害虫 → LED 警示灯 + 弥雾机自动开启
- 环境参数恢复正常后设备自动关闭

#### 阈值设置

- 支持手动设置温度、湿度、光照、土壤湿度、CO₂ 五项阈值
- 支持 AI 推荐阈值（一键填充适宜参数）
- 阈值保存后下发至云端，设备按规则执行

#### 智慧全周期托管

- 需在自动模式下、已绑定作物和生长阶段的前提下开启
- 系统根据作物生长阶段自动配置和更新阈值
- 生长阶段到期自动切换下一阶段，LED 灯光颜色同步适配
- 持续至所有阶段结束后自动关闭

### 4. AI 农业助手（Chat）

- **文字对话**：接入豆包大模型，以"农业智能专家"角色回答种植相关问题
- **流式响应**：支持 Markdown 格式流式输出，打字机效果
- **深度思考模式**：可开关，开启后模型进行更深入推理分析
- **语音对话**：按住说话，调用百度语音识别转文字后发送
- **拍照识病**：调用相机拍摄植物照片，自动填入提示词发送给 AI 分析
- **图片识别**：从相册选择图片发送给 AI 识别
- **会话管理**：支持新建会话、切换历史会话、删除会话
- **历史记录**：按时间排列的会话列表，显示标题和最后消息时间

### 5. 植物百科（Plants）

- 输入植物名称和生长阶段（如"番茄"+"开花期"）
- 调用 AI 接口返回该阶段推荐环境参数（温度、湿度、光照等）
- 附带种植专家建议

### 6. 预警消息（AlertList）

- 当环境参数超出阈值时触发预警通知
- 预警消息按时间倒序排列，显示所属地块和预警内容
- 支持左滑删除单条消息、"全部清空"一键清除
- 未读消息在首页图标红点提示
- 预警轮询间隔为 5 分钟（需通知权限）

### 7. 种植记录（RecordList / RecordDetail）

- **分组管理**：创建/删除种植记录分组
- **记录管理**：在分组内添加种植记录，支持拍照或从相册选择图片，填写描述文字
- **图片预览**：点击记录卡片可全屏预览图片

### 8. 登录注册（Login / Register）

- **注册**：输入邮箱和密码，获取华为 AGC 邮箱验证码后完成注册
- **密码登录**：输入邮箱和密码登录
- **验证码登录**：输入邮箱获取验证码登录
- **退出登录**：在"我的"页面退出当前账号

### 9. 个人中心（Mine）

- 显示用户头像和邮箱
- 设置入口：预警通知开关配置
- 关于我们、客服帮助入口
- 退出登录

### 10. 设置（Settings）

- 预警通知开关（默认开启）

### 11. 客服（CustomerService）

- 展示客服电话号码（比赛用虚拟号码）
- 支持一键拨打（自动填充拨号盘）
- 支持复制号码到剪贴板

### 12. 关于（About）

- 展示应用名称、版本号（v1.0.0）

### 害虫识别与控制流程

```
摄像头实时采集 → AI 害虫目标检测 → 识别到害虫 → LED 警示灯亮 → 弥雾机启动灭杀
                                                                    ↓
                   持续监测 ← 灭杀完成 ← 弥雾机关闭 + LED 熄灭 ← 药液喷射完成
```

## 数据库设计

应用使用 SQLite 关系型数据库（`AgriChat.db`），共 7 张表：

| 表名               | 说明      | 关键字段                                                          |
| ---------------- | ------- | ------------------------------------------------------------- |
| **Greenhouse**   | 地块/大棚信息 | name, deviceId, crop, stage, camUrl, 各类阈值, autoStageEnabled   |
| **AlertMessage** | 预警消息    | ghId, ghName, content, timestamp, isRead                      |
| **EnvRecord**    | 环境记录    | ghId, temp, humi, soil, light, co2, timestamp                 |
| **Session**      | 聊天会话    | title, timestamp                                              |
| **Message**      | 聊天消息    | sessionId, role(user/assistant), content, imageUri, timestamp |
| **RecordGroup**  | 种植记录分组  | name, updateTime                                              |
| **PlantRecord**  | 种植记录    | groupId, imageUri, description, timestamp                     |

## 快速开始

1. 安装 **DevEco Studio**（HarmonyOS NEXT 版本）
2. 克隆项目，在 DevEco Studio 中打开
3. 在 `entry/src/main/ets/config/` 目录下配置各服务的 API Key（参见 `.example` 模板文件）
4. 连接真机或启动模拟器，点击运行

> 注意：`AppConfig.ets`、`IotConfig.ets`、`AuthConfig.ets` 包含密钥信息，已被 `.gitignore` 排除，需自行配置。
